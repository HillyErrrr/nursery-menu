Kitchen Prep · Database

SQLite database

Sets up and checks the database behind Staff admin and the kitchen pages. Until it is set up, everything keeps working from the current storage, exactly as before.

Staff password

1. Set up the database

Copies everything saved today (recipes, ingredients, published menus, menu settings, extra menus and allergy alerts) into the database, checks every item matches, and only then switches over. Creates the users: admin (the staff password) and one login per nursery. Publish backups stay where they are.

Best done when nobody is editing in Staff admin. It takes a few seconds and can be undone with step 3.

2. Check the database

Compares every document with the copy kept in the old storage, and rebuilds each one from the database tables to confirm they hold the same data. Changes nothing.

3. Switch back

Puts everything back in the old storage and turns the database off. Keeps a copy of the database file.
